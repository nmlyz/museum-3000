Museum 3000 is a tiny program that writes one museum label to a file: the label a museum in the year 3000 places next to an ordinary object from today — a hotel key card, read by a curator who takes it at its word.

## Run it

```sh
python3 main.py
```

It writes the label to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
